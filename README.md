PORT SCANNER

Project 2: This project showcases a little about my skills, projects, goals, and journey as a CyberSec student.

ABOUT THIS PROJECT/WHAT IT DOES:

Project 2 is a Port Scanner, once supplied with a range, it will scan those ports and return a list of which are opened/closed, keeping a log of them on a separate file.

TECHNOLOGIES USED:

Python3
Libraries
Socket
Datetime

WHY I BUILT IT:

The code was built with security in mind, ports represent one layer of a systems defence, auditing them is good security hygiene, open ports are more vulnerable to attacks, being able to identify which ports are closed/open are precautionary checks which mean is a port is open and investigation can be opened as to why and a sweep may be done.

HOW TO RUN IT:

Required Libraries:
No external libraries required

Running the code:
Change Start Port and End Port range in code.
